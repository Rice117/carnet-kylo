Si vous lisez ce texte, la page ne s'est pas encore ouverte pour de bon.

Sur iPhone ou iPad. N'ouvrez pas le fichier depuis l'application où vous l'avez reçu : son aperçu ne fait pas tourner les applications. Faites d'abord Partager → Enregistrer dans Fichiers, puis ouvrez-le depuis Fichiers. Si vous ne voyez toujours que ce texte, c'est iPhone qui bloque : ouvrez alors le carnet depuis le magasin (l'adresse en 192.168…) quand vous êtes sur le WiFi de la maison.

Sur ordinateur. Double-cliquez sur le fichier, ou clic droit → « Ouvrir avec » → votre navigateur.
